Jegyfoglaló rendszer
A projekt célja
Ez a projekt egy egyszerű, webes jegyfoglaló rendszer bemutatására készült. A cél a frontend és a backend közötti kommunikáció megismerése.

Alkalmazott technológiák
HTML – a felhasználói felület kialakítása
JavaScript – a program működése
Node.js – a JavaScript szerveroldali futtatása
Express – a backend HTTP-kéréseinek kezelése

Működés
A frontend lekéri a szervertől a nézőtér adatait, megjeleníti az üléseket, majd 
foglalási kérést küld a backendnek.
A backend ellenőrzi, hogy az adott hely szabad-e, és visszajelzést küld a frontendnek.
A projekt fájljai
jegyfoglalo_3.html – frontend
jegyfoglalo_1.js – backend

Fontos megjegyzés
Ez egy tanulóprojekt. A foglalási adatokat a backend jelenlegi változata memóriában tárolja, 
ezért azok a szerver újraindításakor elveszhetnek.
